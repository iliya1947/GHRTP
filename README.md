# GitHub RU Translator (Chrome Extension)

Расширение переводит основные элементы интерфейса GitHub на русский язык.

## Возможности

- Перевод популярных пунктов меню и кнопок GitHub.
- Автоперевод динамически подгружаемых элементов (через `MutationObserver`).
- Включение/выключение перевода через popup расширения.

## Установка (режим разработчика)

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку этого проекта.

## Структура

- `manifest.json` — конфигурация расширения.
- `src/translations.js` — словарь переводов.
- `src/content.js` — логика замены текста на страницах GitHub.
- `popup/*` — интерфейс popup и сохранение настройки.

## Примечание

Перевод основан на локальном словаре. Если какой-то элемент GitHub не перевёлся, добавьте соответствующую фразу в `src/translations.js`.
